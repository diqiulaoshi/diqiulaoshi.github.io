VSCode美化教程(自用)

1.下载VSCode(别告诉我这个没有下):
网址:https://code.visualstudio.com
2.下载扩展:
《Woodfish Theme》《Catppuccin Icons for VSCode》《Carbon Product Icons》 《Custom CSS and JS Loader》(woodfish自带)《indent-rainbow》《Power Mode》
3.下载美化文件(.zip):点这里
4.根据实际情况配置:
先将压缩包解压至某一个目录下,将settings.json文件复制到项目的.vscode文件夹内(没有就自己新建一个), 在settings.json内找到第20行,将引号内的路径改为自己.css文件的路径(绝对路径), 比如"file:///D:/vsstyle.css",保存后,打开命令面板,输入"Reload Custom CSS and JS",重启VSCode就好了
5.该主题简介:
这是一个赛博朋克风的主题,背景为《2026 Dark》的颜色,属于比较黑的颜色,在这基础上,我添加了一些霓虹灯 颜色的描边,主要是霓虹粉和亮青色。
图标方面,我用了《Catppuccin Icons for VSCode》作为文件图标,《Carbon Product Icons》作为产品图标,这两个我都是 用了很久的,十分顺眼,也十分贴合我写的这个美化。
关键字高亮方面,我用了《Woodfish Theme》,这个主题的配色十分好看,有渐变色以及发光效果,支持超多语言(至少有c++ HTML CSS cmake python(￣▽￣))(不支持也不是我的事,反正是直接用的他的主题),即使是不支持的,颜色也不是单一的,比如说纯文本,他会变成 五彩斑斓的白。
细节方面,我添加了《indent-rainbow》扩展,添加了彩虹缩进。以及《Power Mode》扩展,添加了打字特效,默认是粒子效果,不挡视野, 并且我去掉了一些烦人的效果,比如屏幕抖动 连击计数器。通过《Custom CSS and JS Loader》扩展,我将行号换成了更具有科技感的字体。 并且通过《Woodfish Theme》插件,有选中行行号发光的效果,还有渐变色高光。
6.注意事项:
这个美化文件需要rog fonts字体,如果没有这个字体的话,也没事,我在压缩包里还有一些字体,都是免费开源,很好看的。其中,我最推荐 那个液晶显示器字体,就是那个没有放在其他文件夹里的.ttf文件,点击安装。之后,可以到解压出的.css文件里修改为那个字体(把rog fonts改掉),然后打开命令面板,输入"Reload Custom CSS and JS",重启VSCode就好了。
这些东西改好之后VSCode可能会提示Code已损坏,需要重新安装,但其实没事,可能是因为光标等被修改了,是不影响大家正常使用的。
